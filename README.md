# APC-response-programs-TNBC-supplemental-data
Supplemental data for the study "Exploring the Role of APC in Modulating Chemotherapeutic Response in Triple-Negative Breast Cancer Cells"
RF_PLSDA_signature_v4_nestedCV.R # The main program that runs RF, PLSDA, permutation analysis and cross-validation
SessionInfo.txt # Review this file for the exact version of the libraries used
csv files are output by RF_PLSDA_signature_v4_nestedCV.R
It is recommended that you run the code using nohup, as the permutation run is compute intensive.
Additional supplementary files are available with the manuscript.
